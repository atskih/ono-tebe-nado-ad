# Оно тебе надо

Учебная проектная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/atskih/ono-tebe-nado-ad

## Запуск

Откройте `index.html` в браузере. Установка зависимостей, сборка и интернет не требуются: изображения и шрифты находятся в проекте.

По заданию страница имеет фиксированную ширину **1100 px**. Проверяйте её при ширине окна от 1100 px; мобильная версия в этом спринте не предусмотрена.

## Технологии

- Семантическая разметка HTML5.
- CSS: Grid, Flexbox, фоновое изображение и переиспользуемое затемнение.
- Локальные шрифты Raleway в форматах WOFF2 и WOFF.
- Названия классов по БЭМ.

## Структура

- `index.html` — разметка страницы.
- `styles/global.css` — общие стили и сброс браузерных отступов.
- `styles/style.css` — оформление секций и элементов.
- `fonts/` — шрифты и файл их подключения.
- `images/` — изображения и логотипы из заготовки.
- `.github/workflows/tests.yml` — штатная проверка Яндекс Практикума.
